# 📜 File 1 — Transcripts & Extracts

> *Jai Shri Hari.* Raw material from Swami ji's blogs and podcasts. Each entry preserves both **his message** and **his tone of communication** — phrasings, salutations, humor, cadence.

**Conventions**
- `[verbatim]` — extracted directly from a written blog
- `[summary-from-description]` — for YouTube videos where the auto-transcript is not retrievable; summary is taken from the video's title + description + any published transcript snippet
- `[abridged]` — long blog/talk shortened with ellipses, preserving voice

Each entry is wrapped in a header with the source URL, date (if known), and source type. Tone notes are kept in italics at the end.
